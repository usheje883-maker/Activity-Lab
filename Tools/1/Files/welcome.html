About the project

A port of the Aya engine to Webassembly.

Aya is a robust, customizable, and otherwise heavily modified fork of the Roblox client codebase which was leaked to the public internet around March 2016.

What it includes

Engine and DataModel

The instance hierarchy, Lua VM, physics, scene graph, serialization, and compatibility behavior run as native WebAssembly code.

Studio tools

Qt provides the ribbon, Explorer, Properties, script editor, output, diagnostics, and document workflow.

Browser platform

WebGL, Web Audio, browser storage, local file handling, HTTP, keyboard, mouse, and touch replace native platform services.

Version compatibility

Virtual versions from 2012 through 2016 let places opt into the matching Studio behavior before they are loaded.
